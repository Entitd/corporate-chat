# «Поделиться» на Android

После публикации изменений установите сайт как приложение через Chrome
на Android. Сайт должен открываться по HTTPS. Обновлённый манифест
регистрирует «Корпоративный чат» как получателя файлов, текста и ссылок.
Разрешение на push-уведомления не требуется.

Если приложение уже установлено, Chrome должен обновить его регистрацию.
Для проверки новой функции можно удалить установленное приложение и установить
его заново через Chrome. Обычный ярлык сайта не заменяет установку PWA.

## Проверка на телефоне

1. Откройте приложение мессенджера хотя бы один раз после обновления.
2. В «Файлах» или галерее выберите файл → «Поделиться» → «Корпоративный чат».
3. Если потребуется, войдите в аккаунт. Выбранные файлы сохранятся на устройстве.
4. Выберите чат и нажмите «Прикрепить» в верхней панели.
5. Проверьте вложения в редакторе сообщения и нажмите «Отправить».

Работает также передача нескольких файлов (до трёх), текста и ссылок.
Размер каждого файла проверяется по `CHAT_ATTACHMENT_MAX_MB`.
Загрузка на сервер использует обычный механизм Livewire с авторизацией,
проверками и шифрованием файлов при отправке сообщения.

До прикрепления данные находятся только в Cache Storage браузера.
Черновики имеют срок действия один час; просроченные записи удаляются
при следующем приёме файлов либо открытии такого черновика. «Отмена»
удаляет выбранный черновик сразу. После прикрепления локальная копия
черновика удаляется. Для загрузки и отправки требуется соединение с сервером.

Service worker обрабатывает только POST `/chat/share`, сохраняет черновик
и перенаправляет на GET `/chat?share=<id>`. Исключения из CSRF-защиты сервера
не добавлены. Прокси и веб-сервер должны отдавать `/sw.js` и
`/manifest.webmanifest` без авторизации и не перенаправлять `/chat/share`
до обработки service worker.

На iPhone приём файлов через Web Share Target не поддерживается.
