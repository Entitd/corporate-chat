# Загрузка вложений

Чат принимает до трёх файлов. Максимальный размер каждого файла задаётся
целым числом мегабайт в `.env` (по умолчанию 50 МБ):

```dotenv
CHAT_ATTACHMENT_MAX_MB=50
```

После изменения на сервере обновите кеш конфигурации:

```sh
php artisan config:cache
```

Ограничение действует при выборе файлов, вставке, перетаскивании,
временной загрузке Livewire и отправке сообщения. Подсказки в интерфейсе
показывают настроенный размер.

`.env` задаёт лимит приложения. Настройки PHP и Nginx действуют отдельно:
они должны допускать выбранный размер. Например, для 50 МБ на файл:

Для PHP-FPM/CGI параметры заданы в `public/.user.ini`:

```ini
upload_max_filesize = 50M
post_max_size = 160M
```

Общий размер POST допускает три файла и служебные данные формы.
Если сервер отключает `.user.ini`, эти параметры нужно задать в настройках PHP.
Для Nginx также требуется `client_max_body_size 160m;`.

Встроенный сервер PHP не читает `.user.ini`. Локальный запуск из корня проекта:

```sh
php -d upload_max_filesize=50M -d post_max_size=160M -S 127.0.0.1:8000 -t public
```
